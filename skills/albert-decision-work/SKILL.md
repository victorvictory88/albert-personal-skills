# Albert Decision Work

## Default Posture

Give one clear recommendation with tradeoffs for routine operating decisions. Use the full decision pass when the choice has meaningful downside or closes future options.

## Decision Lenses

Use these lenses silently before final synthesis:

- Contrarian: which common assumption may be wrong?
- First Principles: what must be true independent of preference?
- Expansionist: which option creates the most future upside?
- Outsider: what would a capable external operator notice quickly?
- Executor: what can be done now with available people, tools, and time?

Return one synthesis:

- Where the lenses agree
- Where they clash
- The blind spots caught
- The recommendation
- One concrete next step

## Pre-Mortem

For high-stakes decisions, test:

- Three likely failure modes
- Assumptions the recommendation depends on
- Evidence or events that would change the recommendation
- Fixes available before commitment

Address fixable risks before delivery. State any remaining choice plainly.

## Research Boundary

Use `albert-research-synthesis` alongside this skill only when the decision materially depends on current external evidence or conflicting sources. Research owns evidence gathering and source conflict. This skill owns option evaluation, tradeoffs, recommendation, and pre-mortem.

## Output Shape

Lead with the recommendation. Then give the tradeoffs, assumptions, risks, and next step. Label facts, inferences, recommendations, and open questions when the distinction affects judgment.
